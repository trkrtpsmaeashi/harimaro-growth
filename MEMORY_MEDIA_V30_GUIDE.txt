Harimaro Memories v3.0 写真＋動画対応

追加:
- Memoriesに写真と動画を同時アップロード
- 写真と動画を同じ投稿内で左右切り替え
- 動画プレイヤーで再生
- 詳細画面・スライドショー・年表・月間レポート対応
- 閲覧専用メンバーは写真・動画を保存可能
- 動画は1ファイル50MBまで
- PDFフォトブックでは動画を「動画ページ」として表示
  （PDF内では再生できません）

更新手順:
1. ZIPを解凍してGitHubへ上書きアップロード
2. Supabase SQL Editorで
   supabase/memory_media_v30.sql
   を全文貼り付けてRun
3. VercelがReadyになったら更新
4. Memoriesで「写真・動画」を選んで投稿

注意:
- iPhoneで撮影した長い動画は50MBを超えることがあります。
- 最初は30秒前後の短い動画がおすすめです。
- Supabase Storageの容量と転送量を消費します。
